# Typography

All product UI uses Geist Sans: headings, body text, controls, labels, and numbers.

Loaded locally through `geist/font/sans` in `app/layout.tsx`; Tailwind v4 maps `font-sans`, `font-display`, and `font-heading` to `--font-geist-sans`. No external font requests are required.

Use 24px page titles, 16px section headings, 14–16px content, and 12–14px supporting labels. Use tabular numerals for points and progress counts.
